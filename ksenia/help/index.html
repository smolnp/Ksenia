Ksenia M3U Editor — Руководство пользователя

Версия: 0.2.2  |  Платформа: Windows / Linux / macOS

Важно: приложение не содержит встроенных источников

Ksenia M3U Editor — это инструмент, а не каталог.

Приложение не содержит заранее прописанных ссылок на:

  • IPTV-плейлисты (.m3u, .m3u8);
  • EPG (.xml, .xml.gz);
  • FAST-каналы (Pluto, Samsung, Plex, Tubi, Roku, Xumo и т.п.);
  • «известные» репозитории с плейлистами.

Источники добавляет только пользователь — вручную (локальный файл или URL) через «Инструменты → Источники ссылок». Автоматического поиска источников в приложении нет.

EPG не встроен. Пользователь указывает свой источник EPG в «Настройки → Общие настройки → EPG по умолчанию» или в диалоге загрузки при первом запуске.

Юридическая позиция: ответственность за использование конкретных источников лежит на пользователе и определяется законодательством его страны. Разработчик предоставляет нейтральный инструмент для редактирования плейлистов, которые пользователь получил самостоятельно.

Введение

Ksenia M3U Editor — десктопный редактор IPTV-плейлистов формата M3U/M3U8.

Возможности:

  • Открытие, редактирование, сохранение M3U/M3U8.
  • Несколько плейлистов в одном окне (вкладки).
  • Многопоточная проверка ссылок.
  • Автозамена битых ссылок из кэша живых URL.
  • Auto-Repair битых ссылок (http↔https, редиректы).
  • Определение разрешения потока через ffprobe.
  • Измерение TTFB (time to first byte) при проверке.
  • Аудит Content-Type (защита от HTML/JSON вместо потока).
  • Чёрные списки каналов и домен/IP.
  • Правила User-Agent по доменам.
  • EPG (XMLTV) с нечётким поиском.
  • Встроенный плеер mpv.
  • CLI/headless режим.

Установка и запуск

Требования

  • Python 3.10+
  • PyQt6
  • requests, urllib3
  • mpv (для встроенного плеера)
  • ffprobe (опционально, для определения разрешения; входит в пакет FFmpeg)

Установка зависимостей

Debian / Ubuntu / Mint

sudo apt update
sudo apt install -y python3 python3-pip python3-venv \
                    mpv libmpv-dev ffmpeg \
                    libxcb-cursor0 libxcb-xinerama0 \
                    adwaita-icon-theme

Fedora / RHEL

sudo dnf install -y python3 python3-pip \
                    mpv mpv-libs-devel ffmpeg \
                    xcb-util-cursor adwaita-icon-theme

Arch / Manjaro

sudo pacman -S --needed python python-pip \
                        mpv ffmpeg \
                        xcb-util-cursor adwaita-icon-theme

Python-пакеты

pip install PyQt6 requests urllib3

Про ffprobe: определение разрешения — опциональная функция. Если ffprobe не установлен, приложение работает как обычно, просто не показывает разрешение. При попытке определить разрешение появится диалог с инструкцией по установке.

Запуск

python ksenia.py

Важно: встроенный плеер использует mpv --wid, который требует X11 (или XWayland). На «чистом» Wayland запускайте приложение так:

QT_QPA_PLATFORM=xcb python ksenia.py

Первый запуск: что делать

  1. Запустите приложение.
  2. Откройте Инструменты → Источники ссылок.
  3. Нажмите «Добавить» и укажите свой источник: локальный файл или URL (http/https).
  4. Нажмите «🔄 Обновить всё», чтобы загрузить каналы и наполнить кэш живых URL.
  5. Файл → Создать плейлист из источников… или Файл → Открыть — начните работу.

EPG (программа передач) — опционально: Настройки → Общие настройки → EPG по умолчанию — укажите свой URL (например, http://example.com/epg.xml).

Для определения фактического разрешения потоков установите FFmpeg (включает ffprobe) — см. раздел «Установка».

Колонки: № | Название | Группа | TVG-ID | Логотип | Catchup | Качество | URL

Дополнительные колонки (включаются в «Настройки → Общие настройки»):

  • Качество — фактическое разрешение (SD / 720p / 1080p / 4K), определённое через ffprobe. Показывается цветом. В файл M3U не пишется.

Цветовая индикация URL:

  • ● работает
  • ● не работает
  • ● не проверен
  • ● неподдерживаемый протокол
  • ● нет URL
  • ● светло-зелёный фон — есть User-Agent

Цветовая индикация разрешения:

  • ● 4K
  • ● 1080p
  • ● 720p
  • ● SD / прочее

Работа с плейлистами

Открытие

Файл → Открыть (Ctrl+O).

Поддержка кодировок: UTF-8, UTF-8-BOM, Windows-1251, CP1251.

Создание

Файл → Новый (Ctrl+N).

Сохранение

  • Ctrl+S — сохранить.
  • Ctrl+Shift+S — Сохранить как.
  • Файл → Сохранить всё — все вкладки.

Перед сохранением создаётся .bak (если включено).

Экспорт / импорт

  • Экспорт в CSV/JSON — все поля канала, включая resolution и ttfb_ms.
  • Импорт — добавить каналы из другого файла.
  • Stable-экспорт — с живой проверкой URL.

Экспорт/импорт настроек

Настройки → Экспорт настроек… — сохраняет все параметры в JSON (включая ширины столбцов таблицы).

Настройки → Импорт настроек… — загружает JSON и заменяет текущие настройки. После импорта требуется перезапуск приложения.

Редактирование каналов

Добавление

Каналы → Новый канал (Ctrl+Shift+A) или правый клик.

Удаление

  • Delete — текущий.
  • Ctrl+Shift+Delete — выбранные.
  • Каналы → Удалить каналы → Без ссылок.
  • Каналы → Удалить каналы → Без метаданных.
  • Каналы → Удалить каналы → Без групп (удаляет каналы, у которых group-title пустой или равен «Без группы»).

Перемещение

  • Ctrl+↑ / Ctrl+↓ — текущий.
  • Ctrl+Shift+↑ / Ctrl+Shift+↓ — группа.
  • Drag & drop строк в таблице.

Поиск

  • Обычный: по названию, группе, TVG-ID, URL, разрешению.
  • Спец-префиксы:
    • is:orphan — без URL, но с метаданными.
    • is:broken — нерабочие.
    • is:working — рабочие.

Undo/Redo

Ctrl+Z / Ctrl+Y. История до 100 состояний.

Ссылки и проверка

Проверка

  • Ссылки → Проверить все ссылки.
  • Ссылки → Проверить выбранные ссылки.
  • Правый клик → Проверить ссылку.

Многопоточно (до 20 потоков), результаты кэшируются. Если в «Общих настройках» включён «Ограничивать число проверок», будет проверено не более max_channels_to_check каналов.

При проверке измеряется:

  • HTTP-код и время ответа.
  • TTFB (time to first byte) — время до получения заголовков ответа.
  • Content-Type — если сервер отдаёт text/html или application/json вместо видеопотока, канал помечается отдельным статусом (ссылка «жива», но не играет).

ffprobe при массовой проверке не запускается (это отдельная операция, см. раздел «Определение разрешения»).

Auto-Repair (автопочинка битых ссылок)

Перед обращением к кэшу живых URL приложение пытается починить битую ссылку:

  • Меняет схему http:// ↔ https://.
  • Следует по редиректам (до 5 шагов) и берёт финальный URL.

Если починка удалась — ссылка обновляется, а в подсказке канала появляется пометка «🔧 Починена». Если нет — тогда используется кэш живых URL.

Заблокированные ЧС ссылки не чинятся. Если результат Auto-Repair ведёт на ЧС-домен — он отбрасывается.

Исправление ссылок

Меню Ссылки → Исправить ссылки содержит три режима:

  • Битые ссылки — обрабатываются только каналы, у которых url_status is False (или нет URL, если включён auto_replace_missing).
  • Выбранные ссылки — обрабатываются только выделенные каналы. Открывается диалог выбора альтернатив.
  • Все ссылки — обрабатываются все каналы, требующие замены. Если кэш живых URL пуст — предлагается открыть менеджер источников и нажать «🔄 Обновить всё».

Порядок работы:

  1. Auto-Repair текущей ссылки (если она есть).
  2. Поиск из кэша живых URL.

Внимание: кэш живых URL наполняется кнопкой «🔄 Обновить всё» в источниках. Если кэш пуст и Auto-Repair не помог — заменено будет 0.

Удаление ссылок

Меню Ссылки → Удалить ссылки содержит три режима:

  • Битые — очищает URL только у каналов со статусом «не работает» (url_status is False). Каналы сохраняются.
  • Выбранные — очищает URL у выделенных каналов. Каналы сохраняются.
  • Все — очищает URL у всех каналов. Каналы сохраняются.

Определение разрешения (ffprobe)

Меню Каналы → 🎬 Определить разрешение (ffprobe) содержит три пункта:

  • Текущего канала — только текущий канал;
  • Выбранных каналов — все выделенные каналы;
  • Всех каналов с URL — все каналы, у которых есть URL.

Также доступно в контекстном меню таблицы.

Результат отображается:

  • цветными цифрами в колонке «Качество»;
  • в подсказке канала («Разрешение: 1080p»).

Результат НЕ записывается в M3U. Это информационное поле, оно хранится только в кэше проверок и в текущей сессии.

Требуется установленный FFmpeg (включает ffprobe). Если ffprobe не найден — появится диалог с инструкцией по установке, остальные функции работают как обычно.

Источники ссылок

Приложение не содержит встроенных источников и не выполняет автоматический поиск. Источники добавляет только пользователь.

Менеджер

Инструменты → Источники ссылок.

Возможности:

  • Добавить / редактировать / удалить.
  • Включить / выключить.
  • Приоритет 1–10.
  • Автообновление (по расписанию).
  • 🔄 Обновить всё.
  • Импорт / экспорт JSON.

Добавление источника

Нажмите «Добавить» и укажите:

  • Тип: «Локальный файл» или «Онлайн источник».
  • Путь/URL: локальный файл (через «Обзор...») или http(s)://….
  • Название — произвольное.
  • Приоритет 1–10 (1 — выше).

Опции «Применять чёрный список каналов» и «Очищать ссылки по ЧС домен/IP» управляют фильтрацией при загрузке.

«🔄 Обновить всё»

Запускает SourcesRefreshWorker:

  1. Загрузка каналов из всех включённых источников.
  2. Проверка всех URL (без ffprobe — быстро).
  3. Запись в кэш.
  4. Перестройка alive-индекса.

Обязательный шаг перед автозаменой из кэша.

Чёрные списки

ЧС каналов

Инструменты → Менеджер ЧС каналов.

Правило: имя и/или TVG-ID. Канал удаляется.

ЧС домен/IP

Инструменты → Менеджер ЧС домен/IP.

Правило: домен (с поддоменами) или IP. Ссылка очищается, канал остаётся, статус «🚫 Заблокирован ЧС домен/IP».

EPG

Встроенного EPG нет. Пользователь указывает свой URL в «Настройки → Общие настройки → EPG по умолчанию» или в диалоге загрузки.

Загрузка

Инструменты → Загрузить EPG. Поддержка XMLTV и XMLTV.GZ.

Если в шапке плейлиста нет url-tvg, приложение предложит:

  1. использовать «EPG по умолчанию» из настроек (если он задан);
  2. или ввести URL вручную.

Применение

Инструменты → Применить метаданные из EPG ко всем каналам.

Обновляет: tvg-id, tvg-name, tvg-logo, tvg-chno, epg_source.

Имя канала не перезаписывается.

Встроенный плеер (mpv)

Требования

  • Установленный mpv в PATH.
  • X11 или XWayland (на «чистом» Wayland используйте QT_QPA_PLATFORM=xcb).

Запуск

Двойной клик по каналу с URL, правый клик → Смотреть в плеере, или ▶ на панели.

Возможности

  • Воспроизведение с плейлистом текущего фильтра.
  • Переключение «Пред./След.».
  • Громкость, аспект (16:9, 4:3, 1:1).
  • Выбор аудио/видеодорожек, сохранение предпочтений.
  • Альтернативные ссылки из кэша источников.
  • Удаление ссылки, блокировка домена/IP.
  • Медиа-инфо, полноэкранный режим.

Кэш

SQLite

cache/editor_cache.db: url_status_cache, epg_entries, epg_channels, normalized_index.

В таблице url_status_cache хранятся, в том числе: ttfb_ms (time to first byte, мс) и resolution (например, «1080p», «4K»).

Файловый кэш

cache/link_cache/*.json — по SHA-256 ключу URL.

Управление

Инструменты → Управление кэшем. Вкладки: Проверки, LinkCache, EPG.

При уменьшении TTL в настройках старые записи инвалидируются автоматически.

Настройки

Общие

Настройки → Общие настройки: шрифт, EXTVLCOPT, лимит проверок, дубликаты, ЧС при открытии, EPG-перезапись, порядок, отображение колонок, статус-бар, иконки, автообновление пользовательских источников, автобэкап, EPG по умолчанию, пути к ffprobe и mpv, кодировка при «Сохранить как», авто-проверка ссылок.

Диалог разбит на вкладки:

  • Основные — общие параметры, шрифт, EPG по умолчанию, кодировка.
  • Внешние приложения — пути к ffprobe и mpv.
  • Проверка ссылок — авто-проверка при открытии и по расписанию.

В диалоге есть кнопка «Сбросить» — возвращает все параметры к значениям по умолчанию.

Замена ссылок

Настройки → Настройки замены ссылок:

  • Поиск — тип, порог, схожесть.
  • Нормализация — спецсимволы, скобки, эмодзи.
  • Автозамена — потоки, таймауты, кэш.
  • Сеть — таймауты, потоки, SSL.
  • Фильтрация — ЧС, домены.
  • EPG-метаданные — перезапись, нечёткий поиск.

При «Точном совпадении» пороги скрываются/дизейблятся. При включении «⚡ Быстрой замены» дизейблятся таймауты, повторы и проверка кандидатов. При выключении нечёткого поиска EPG дизейблятся его пороги.

В диалоге есть кнопка «Сбросить».

Экспорт / импорт

Настройки → Экспорт настроек… — сохраняет editor_config.json и ширины столбцов в один JSON.

Настройки → Импорт настроек… — загружает JSON и заменяет текущие настройки. После импорта требуется перезапуск приложения.

CLI

Запуск

python ksenia.py --headless --sources-file sources.json \
    --export output.m3u --export-stable

Параметры

ПараметрОписание
--headlessБез GUI
--sources-file JSON-файл источников (пользовательских)
--exportПуть M3U
--export-stable С живой проверкой
--check-workers N Воркеры (8)
--timeout N Таймаут, сек (5)
--epg-url URL URL EPG (опционально)
--versionВерсия

FAQ

Где настройки?
Linux — ~/.config/ksenia/, macOS — ~/Library/Application Support/Ksenia/, Windows — %APPDATA%\Ksenia\.

Почему приложение не содержит источников?
См. раздел «Важно: приложение не содержит встроенных источников». Юридически безопаснее предоставлять нейтральный инструмент, а не каталог.

Как добавить источник?
Инструменты → Источники ссылок → «Добавить». Приложение не ищет источники автоматически — их добавляет только пользователь.

Как заменить все битые ссылки?

  1. Сначала приложение пытается починить каждую битую ссылку (http↔https, редиректы).
  2. Если не удалось — используется кэш живых URL. Кэш наполняется кнопкой Инструменты → Источники → 🔄 Обновить всё.
  3. Ссылки → Исправить ссылки → Битые ссылки (или «Все ссылки», если нужно обработать все требующие замены).

Почему автозамена не находит ничего?
Auto-Repair не смог починить, а кэш живых URL пуст. Запустите «🔄 Обновить всё».

Как узнать разрешение потока?
Меню Каналы → 🎬 Определить разрешение (ffprobe) → «Текущего канала» / «Выбранных каналов» / «Всех каналов с URL». Или правый клик по каналу → «🎬 Определить разрешение». Результат показывается цветом в колонке «Качество» и в подсказке, в M3U не пишется.

Почему нет разрешения?
Возможно, не установлен ffprobe. См. раздел «Установка». Или поток медленный и ffprobe не уложился в 5 секунд.

Как удалить ссылку, оставив канал?
Ссылки → Удалить ссылки → Выбранные (или «Все», или «Битые»). Каналы сохраняются.

Как удалить каналы без группы?
Каналы → Удалить каналы → Без групп. Удаляются каналы, у которых group-title пустой или равен «Без группы».

Плеер не запускается на Wayland.
Запустите приложение с QT_QPA_PLATFORM=xcb.

Где взять EPG?
Приложение не содержит встроенного EPG. Укажите свой источник в Настройки → Общие настройки → EPG по умолчанию.

Решение проблем

Не запускается

  1. Python 3.10+: python --version.
  2. pip install -r requirements.txt.
  3. Лог: ~/.config/ksenia/editor.log.

mpv не найден

# Linux
sudo apt install mpv

ffprobe не найден

# Linux
sudo apt install ffmpeg
# macOS
brew install ffmpeg
# Windows: https://ffmpeg.org/download.html

Без ffprobe приложение работает, но не показывает разрешение.

Ошибка SSL

Отключите проверку SSL в настройках сети.

Соглашения

Термины

Термин Что это Где используется
Ссылка (URL) Адрес потока, например http://example.com/stream.m3u8 В UI — «ссылка», в колонке таблицы — «ссылка», в CLI — «URL»
Чёрный список (ЧС) Список запрещённых каналов, доменов или IP В UI — «чёрный список», в меню — «чёрный список» (полная форма)
Проигрыватель (плеер) Встроенный mpv В UI — «проигрыватель», в tooltip — «плеер» (допустимо)
EPG (программа передач) Electronic Program Guide, XMLTV В UI — «EPG», при первом упоминании — «EPG (программа передач)»
Автопочинка (Auto-Repair) Автоматическое исправление битой ссылки (http↔https, редиректы) В UI — «автопочинка», в логах — «Auto-Repair»
Стабильный экспорт Экспорт с живой проверкой URL В UI — «стабильный экспорт», в коде — «stable»
Режим без интерфейса CLI-режим без GUI В UI — «режим без интерфейса», в CLI — «headless»
Источник (плейлист) Пользовательский плейлист (локальный файл или URL), добавленный вручную В UI — «источник», в коде — «source»
Домен/IP Доменное имя (example.com) или IP-адрес (192.168.1.1) В UI — «домен/IP» (им.) или «доменов/IP» (род.)

Формы слов

В UI используются правильные формы слов после числительных:

  • 1 канал, 2 канала, 5 каналов
  • 1 ссылка, 2 ссылки, 5 ссылок
  • 1 правило, 2 правила, 5 правил
  • 1 источник, 2 источника, 5 источников
  • 1 ошибка, 2 ошибки, 5 ошибок

Если вы видите «1 каналов» или «канал(ов)» — это баг, сообщите о нём.
