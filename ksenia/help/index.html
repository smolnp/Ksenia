Ksenia M3U Editor — Руководство пользователя

Версия: 0.2.3  |  Платформа: Windows / Linux / macOS

Что это за программа?
Редактор IPTV-плейлистов формата M3U/M3U8 с проверкой ссылок, автозаменой битых URL, чёрными списками, EPG и встроенным плеером mpv. Приложение нейтральное: в нём нет встроенных плейлистов и EPG — источники вы добавляете сами.

Быстрый старт

Если вы только что установили Ksenia M3U Editor — сделайте эти пять шагов, и вы уже работаете с плейлистом.

  1. Откройте или создайте плейлист.
    Ctrl+O — открыть готовый .m3u/.m3u8, или Ctrl+N — начать с пустого.
  2. Проверьте ссылки.
    Меню Ссылки → Проверить все ссылки. Программа параллельно опросит URL и покрасит их: зелёные работают, красные — нет, жёлтые — не проверены.
  3. Почините битые ссылки.
    Меню Ссылки → Исправить ссылки → Битые ссылки. Сначала сработает Auto-Repair (http↔https, редиректы), затем — кэш живых URL.
  4. Сохраните результат.
    Ctrl+S — перезаписать, Ctrl+Shift+S — в новый файл.
  5. Хотите смотреть?
    Двойной клик по каналу или ▶ на панели — откроется встроенный плеер mpv.
Совет: если планируете пользоваться автозаменой битых ссылок, сначала наполните кэш живых URL — Инструменты → Источники ссылок → 🔄 Обновить всё. Без этого шага заменять будет нечем.

Важно: приложение не содержит встроенных источников

Ksenia M3U Editor — это инструмент, а не каталог.

В программе нет заранее прописанных ссылок на:

  • IPTV-плейлисты (.m3u, .m3u8);
  • EPG (.xml, .xml.gz);
  • FAST-каналы (Pluto, Samsung, Plex, Tubi, Roku, Xumo и т.п.);
  • «известные» репозитории с плейлистами.

Источники добавляет только пользователь — вручную, через Инструменты → Источники ссылок. Автоматического поиска в приложении нет.

EPG тоже не встроен. Свой источник указывается в Настройки → Общие настройки → EPG по умолчанию или в диалоге загрузки при первом запуске.

Юридическая позиция. Ответственность за использование конкретных источников лежит на пользователе и определяется законодательством его страны. Разработчик предоставляет нейтральный инструмент для редактирования плейлистов, которые пользователь получил самостоятельно.

Что умеет программа

  • Открывать, редактировать и сохранять M3U/M3U8.
  • Держать несколько плейлистов во вкладках одного окна.
  • Проверять ссылки в несколько потоков.
  • Чинить битые ссылки: Auto-Repair + кэш живых URL.
  • Определять реальное разрешение потока через ffprobe.
  • Измерять TTFB — время до первого байта.
  • Ловить подмену потока на HTML/JSON (вместо видео).
  • Вести чёрные списки каналов и доменов/IP.
  • Задавать User-Agent для отдельных доменов.
  • Загружать EPG (XMLTV) и искать по нему с нечётким совпадением.
  • Проигрывать каналы во встроенном плеере mpv.
  • Работать из командной строки (headless-режим).

Первый запуск: что делать

  1. Откройте Инструменты → Источники ссылок.
  2. Нажмите «Добавить» и укажите свой источник: локальный файл или URL (http/https).
  3. Нажмите 🔄 Обновить всё — программа загрузит каналы и наполнит кэш живых URL.
  4. Дальше: Файл → Создать плейлист из источников… или Файл → Открыть.

EPG (программа передач) — по желанию: Настройки → Общие настройки → EPG по умолчанию, укажите свой URL (например, http://example.com/epg.xml).

Для определения разрешения потоков установите FFmpeg (в нём есть ffprobe). Без него программа работает, просто не показывает разрешение.

Интерфейс

Главное окно

  • Вкладки — по одной на плейлист.
  • Поиск — строка с фильтрами и спец-префиксами.
  • Фильтр групп — выпадающий список групп.
  • Фильтр статуса — Всего / С URL / Без URL / Работают / Не работают / Не проверены.
  • Таблица каналов — основная рабочая область.
  • Строка состояния — текущее действие, статистика, прогресс.

Таблица каналов

Колонки по умолчанию: № | Название | Группа | TVG-ID | Логотип | Catchup | Качество | URL

Колонка «Качество» — реальное разрешение (SD / 720p / 1080p / 4K), определённое через ffprobe. Показывается цветом и не записывается в M3U.

Цвет ссылки:

  • ● работает
  • ● не работает
  • ● не проверена
  • ● неподдерживаемый протокол
  • ● нет URL
  • ● светло-зелёный фон — задан User-Agent

Цвет качества:

  • ● 4K
  • ● 1080p
  • ● 720p
  • ● SD / прочее

Работа с плейлистами

Открыть

Файл → Открыть (Ctrl+O).

Поддерживаются кодировки UTF-8, UTF-8-BOM, Windows-1251, CP1251.

Создать

Файл → Новый (Ctrl+N).

Сохранить

  • Ctrl+S — сохранить.
  • Ctrl+Shift+S — Сохранить как.
  • Файл → Сохранить всё — все вкладки.

Перед сохранением создаётся .bak (если включено в настройках).

Экспорт и импорт

  • Экспорт в CSV/JSON — все поля канала, включая resolution и ttfb_ms.
  • Импорт — добавить каналы из другого файла.
  • Стабильный экспорт — с живой проверкой URL.

Экспорт и импорт настроек

Настройки → Экспорт настроек… сохраняет все параметры (включая ширины столбцов) в один JSON. Импорт настроек… загружает JSON и заменяет текущие настройки. После импорта нужен перезапуск.

Редактирование каналов

Добавить

Каналы → Новый канал (Ctrl+Shift+A) или правый клик.

Удалить

  • Delete — текущий канал.
  • Ctrl+Shift+Delete — выбранные.
  • Каналы → Удалить каналы → Без ссылок.
  • Каналы → Удалить каналы → Без метаданных.
  • Каналы → Удалить каналы → Без групп (удаляет каналы с пустым group-title или «Без группы»).

Переместить

  • Ctrl+↑ / Ctrl+↓ — текущий канал.
  • Ctrl+Shift+↑ / Ctrl+Shift+↓ — группой.
  • Или просто перетащите строки мышкой.

Поиск

  • Обычный: по названию, группе, TVG-ID, URL, разрешению.
  • Спец-префиксы:
    • is:orphan — без URL, но с метаданными;
    • is:broken — нерабочие;
    • is:working — рабочие.

Отмена и повтор

Ctrl+Z / Ctrl+Y. История — до 100 состояний.

Ссылки и проверка

Как проверить

  • Ссылки → Проверить все ссылки.
  • Ссылки → Проверить выбранные ссылки.
  • Или правый клик → Проверить ссылку.

Проверка идёт параллельно (до 8 потоков, число настраивается в «Настройках замены ссылок»), результаты кэшируются. Если в «Общих настройках» включено ограничение — будет проверено не больше max_channels_to_check каналов.

При проверке измеряется:

  • HTTP-код и время ответа.
  • TTFB — время до первого байта.
  • Content-Type — если сервер отдаёт text/html или application/json вместо видео, канал помечается отдельным статусом («ссылка жива, но не играет»).

ffprobe при массовой проверке не запускается — это отдельная операция (см. «Определение разрешения»).

Auto-Repair — автопочинка битых ссылок

Перед обращением к кэшу живых URL программа пытается починить ссылку:

  • меняет схему http:// ↔ https://;
  • идёт по редиректам (до 5 шагов) и берёт финальный URL.

Если починка удалась — ссылка обновляется, а в подсказке канала появляется пометка «🔧 Починена». Если нет — используется кэш живых URL.

Заблокированные ЧС ссылки не чинятся. Если результат Auto-Repair ведёт на ЧС-домен, он отбрасывается.

Исправить ссылки

Меню Ссылки → Исправить ссылки — три режима:

  • Битые ссылки — только каналы, у которых url_status is False (или нет URL, если включён auto_replace_missing).
  • Выбранные ссылки — только выделенные каналы. Открывается диалог выбора альтернатив.
  • Все ссылки — все каналы, требующие замены. Если кэш живых URL пуст — программа предложит открыть менеджер источников и нажать «🔄 Обновить всё».

Порядок работы:

  1. Auto-Repair текущей ссылки (если она есть).
  2. Поиск в кэше живых URL.
Внимание. Кэш живых URL наполняется кнопкой «🔄 Обновить всё» в источниках. Если кэш пуст и Auto-Repair не помог — заменено будет 0.

Удалить ссылки

  • Битые — очищает URL у каналов со статусом «не работает» (url_status is False). Каналы остаются.
  • Выбранные — очищает URL у выделенных каналов. Каналы остаются.
  • Все — очищает URL у всех каналов. Каналы остаются.

Определение разрешения (ffprobe)

Меню Каналы → 🎬 Определить разрешение (ffprobe):

  • Текущего канала — только текущий;
  • Выбранных каналов — все выделенные;
  • Всех каналов с URL — все каналы с URL.

Также доступно из контекстного меню таблицы.

Результат:

  • цветные цифры в колонке «Качество»;
  • строка «Разрешение: 1080p» в подсказке канала.

В M3U не записывается. Это информационное поле, живёт только в кэше проверок и в текущей сессии.

Нужен установленный FFmpeg (в нём ffprobe). Если ffprobe не найден — появится диалог с инструкцией, остальные функции работают как обычно.

Источники ссылок

Встроенных источников нет, автоматического поиска тоже нет. Источники добавляет только пользователь.

Менеджер источников

Инструменты → Источники ссылок.

Умеет:

  • добавлять, редактировать и удалять;
  • включать и выключать;
  • задавать приоритет 1–10;
  • автообновление по расписанию;
  • 🔄 Обновить всё;
  • импорт и экспорт JSON.

Как добавить источник

Нажмите «Добавить» и заполните:

  • Тип — «Локальный файл» или «Онлайн источник».
  • Путь/URL — файл (через «Обзор...») или http(s)://….
  • Название — произвольное.
  • Приоритет 1–10 (1 — выше).

Опции «Применять чёрный список каналов» и «Очищать ссылки по ЧС домен/IP» управляют фильтрацией при загрузке.

«🔄 Обновить всё»

Запускает SourcesRefreshWorker:

  1. загружает каналы из всех включённых источников;
  2. проверяет все URL (без ffprobe, быстро);
  3. пишет результаты в кэш;
  4. перестраивает alive-индекс.
Обязательный шаг перед автозаменой из кэша.

Чёрные списки

ЧС каналов

Инструменты → Менеджер ЧС каналов.

Правило: имя и/или TVG-ID. Канал удаляется.

ЧС доменов/IP

Инструменты → Менеджер ЧС домен/IP.

Правило: домен (с поддоменами) или IP. Ссылка очищается, канал остаётся, статус — «🚫 Заблокирован ЧС домен/IP».

EPG

Встроенного EPG нет. Пользователь указывает свой URL в «Настройки → Общие настройки → EPG по умолчанию» или в диалоге загрузки.

Загрузка

Инструменты → Загрузить EPG. Поддержка XMLTV и XMLTV.GZ.

Если в шапке плейлиста нет url-tvg, программа предложит:

  1. использовать «EPG по умолчанию» из настроек (если задан);
  2. или ввести URL вручную.

Применение

Инструменты → Применить метаданные из EPG ко всем каналам.

Обновляет: tvg-id, tvg-name, tvg-logo, tvg-chno, epg_source.

Имя канала не перезаписывается.

Встроенный плеер (mpv)

Что нужно

  • Установленный mpv в PATH.
  • X11 или XWayland (на «чистом» Wayland запускайте программу с QT_QPA_PLATFORM=xcb).

Как запустить

Двойной клик по каналу с URL, правый клик → Смотреть в плеере, или ▶ на панели.

Что умеет

  • Проигрывать плейлист из текущего фильтра.
  • Переключать «Пред./След.».
  • Менять громкость, аспект (16:9, 4:3, 1:1).
  • Выбирать аудио/видеодорожки, запоминать предпочтения.
  • Подхватывать альтернативные ссылки из кэша источников.
  • Удалять ссылку, блокировать домен/IP.
  • Показывать медиа-инфо, включать полноэкранный режим.

Кэш

SQLite

cache/editor_cache.db содержит таблицы url_status_cache, epg_entries, epg_channels, normalized_index.

В url_status_cache хранятся, в том числе, ttfb_ms (время до первого байта, мс) и resolution (например, «1080p», «4K»).

Файловый кэш

cache/link_cache/*.json — по SHA-256 ключу URL.

Управление

Инструменты → Управление кэшем. Вкладки: Проверки, LinkCache, EPG.

При уменьшении TTL в настройках старые записи инвалидируются автоматически.

Настройки

Общие настройки

Настройки → Общие настройки: шрифт, EXTVLCOPT, лимит проверок, дубликаты, ЧС при открытии, EPG-перезапись, порядок, отображение колонок, статус-бар, иконки, автообновление пользовательских источников, автобэкап, EPG по умолчанию, пути к ffprobe и mpv, кодировка при «Сохранить как», авто-проверка ссылок.

Диалог разбит на вкладки:

  • Основные — общие параметры, шрифт, EPG по умолчанию, кодировка.
  • Внешние приложения — пути к ffprobe и mpv.
  • Проверка ссылок — авто-проверка при открытии и по расписанию.

Кнопка «Сбросить» возвращает все параметры к значениям по умолчанию.

Настройки замены ссылок

Настройки → Настройки замены ссылок:

  • Поиск — тип, порог, схожесть.
  • Нормализация — спецсимволы, скобки, эмодзи.
  • Автозамена — потоки, таймауты, кэш.
  • Сеть — таймауты, потоки, SSL.
  • Фильтрация — ЧС, домены.
  • EPG-метаданные — перезапись, нечёткий поиск.

При «Точном совпадении» пороги скрываются. При включении «⚡ Быстрой замены» дизейблятся таймауты, повторы и проверка кандидатов. При выключении нечёткого поиска EPG дизейблятся его пороги.

Кнопка «Сбросить» — сброс к значениям по умолчанию.

Экспорт и импорт

Экспорт настроек… сохраняет editor_config.json и ширины столбцов в один JSON. Импорт настроек… загружает JSON и заменяет текущие настройки. После импорта требуется перезапуск.

Запуск

python ksenia.py --headless --sources-file sources.json \
    --export output.m3u --export-stable

Параметры

ПараметрОписание
--headlessБез GUI
--sources-file JSON-файл источников (пользовательских)
--exportПуть M3U
--export-stable С живой проверкой
--check-workers N Воркеры (по умолчанию 8)
--timeout N Таймаут, сек (по умолчанию 5)
--epg-url URL URL EPG (опционально)
--versionВерсия

FAQ

Где настройки?
Linux — ~/.config/ksenia/, macOS — ~/Library/Application Support/Ksenia/, Windows — %APPDATA%\Ksenia\.

Почему в программе нет источников?
См. «Важно: приложение не содержит встроенных источников». Юридически безопаснее дать нейтральный инструмент, а не каталог.

Как добавить источник?
Инструменты → Источники ссылок → «Добавить». Программа не ищет источники автоматически — их добавляет только пользователь.

Как заменить все битые ссылки?

  1. Сначала программа пытается починить каждую битую ссылку (http↔https, редиректы).
  2. Если не удалось — используется кэш живых URL. Кэш наполняется кнопкой Инструменты → Источники → 🔄 Обновить всё.
  3. Ссылки → Исправить ссылки → Битые ссылки (или «Все ссылки», если нужно обработать все требующие замены).

Почему автозамена ничего не находит?
Auto-Repair не смог починить, а кэш живых URL пуст. Запустите «🔄 Обновить всё».

Как узнать разрешение потока?
Меню Каналы → 🎬 Определить разрешение (ffprobe) → «Текущего канала» / «Выбранных каналов» / «Всех каналов с URL». Или правый клик → «🎬 Определить разрешение». Результат показывается цветом в колонке «Качество» и в подсказке, в M3U не пишется.

Почему нет разрешения?
Возможно, не установлен ffprobe (см. README.md). Или поток медленный, и ffprobe не уложился в 5 секунд.

Как удалить ссылку, оставив канал?
Ссылки → Удалить ссылки → Выбранные (или «Все», или «Битые»). Каналы сохраняются.

Как удалить каналы без группы?
Каналы → Удалить каналы → Без групп. Удаляются каналы, у которых group-title пустой или равен «Без группы».

Плеер не запускается на Wayland.
Запустите программу с QT_QPA_PLATFORM=xcb.

Где взять EPG?
Встроенного EPG нет. Укажите свой источник в Настройки → Общие настройки → EPG по умолчанию.

Если что-то пошло не так

Программа не запускается

  1. Проверьте Python 3.10+: python --version.
  2. Поставьте зависимости: pip install -r requirements.txt (подробнее — в README.md).
  3. Смотрите лог: ~/.config/ksenia/editor.log.

mpv не найден

# Linux
sudo apt install mpv

ffprobe не найден

# Linux
sudo apt install ffmpeg
# macOS
brew install ffmpeg
# Windows
https://ffmpeg.org/download.html

Без ffprobe программа работает, просто не показывает разрешение.

Ошибка SSL

Отключите проверку SSL в настройках сети (или добавьте домен в SSL-исключения, если такая опция доступна).

Соглашения

Термины

Термин Что это Где встречается
Ссылка (URL) Адрес потока, например http://example.com/stream.m3u8 В UI — «ссылка», в колонке таблицы — «ссылка», в CLI — «URL»
Чёрный список (ЧС) Список запрещённых каналов, доменов или IP В UI — «чёрный список»
Проигрыватель (плеер) Встроенный mpv В UI — «проигрыватель», в подсказке — «плеер»
EPG (программа передач) Electronic Program Guide, XMLTV В UI — «EPG», при первом упоминании — «EPG (программа передач)»
Автопочинка (Auto-Repair) Автоматическое исправление битой ссылки (http↔https, редиректы) В UI — «автопочинка», в логах — «Auto-Repair»
Стабильный экспорт Экспорт с живой проверкой URL В UI — «стабильный экспорт», в коде — «stable»
Режим без интерфейса CLI-режим без GUI В UI — «режим без интерфейса», в CLI — «headless»
Источник (плейлист) Пользовательский плейлист (локальный файл или URL), добавленный вручную В UI — «источник», в коде — «source»
Домен/IP Доменное имя (example.com) или IP-адрес (192.168.1.1) В UI — «домен/IP» (им.) или «доменов/IP» (род.)

Формы слов

В UI используются правильные формы после числительных:

  • 1 канал, 2 канала, 5 каналов
  • 1 ссылка, 2 ссылки, 5 ссылок
  • 1 правило, 2 правила, 5 правил
  • 1 источник, 2 источника, 5 источников
  • 1 ошибка, 2 ошибки, 5 ошибок

Если видите «1 каналов» или «канал(ов)» — это баг, сообщите о нём.
