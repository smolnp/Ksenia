Ksenia M3U Editor — Руководство пользователя

Версия: 0.4.0  |  Платформа: Windows / Linux / macOS

Важно: приложение не содержит встроенных источников

Ksenia M3U Editor — это инструмент, а не каталог.

Приложение не содержит заранее прописанных ссылок на:

  • IPTV-плейлисты (.m3u, .m3u8);
  • EPG (.xml, .xml.gz);
  • FAST-каналы (Pluto, Samsung, Plex, Tubi, Roku, Xumo и т.п.);
  • «известные» репозитории с плейлистами.

Источники добавляет пользователь — вручную (локальный файл или URL) или через «🔍 Найти источники автоматически». Авто-поиск — это live-запрос к GitHub API в момент выполнения: конкретные URL не зашиты в программу, они приходят в ответе API.

EPG не встроен. Пользователь указывает свой источник EPG в «Настройки → Общие → EPG по умолчанию» или в диалоге загрузки при первом запуске.

Юридическая позиция: ответственность за использование конкретных источников лежит на пользователе и определяется законодательством его страны. Разработчик предоставляет нейтральный инструмент для редактирования плейлистов, которые пользователь получил самостоятельно.

Введение

Ksenia M3U Editor — десктопный редактор IPTV-плейлистов формата M3U/M3U8.

Возможности:

  • Открытие, редактирование, сохранение M3U/M3U8.
  • Несколько плейлистов в одном окне (вкладки).
  • Многопоточная проверка ссылок.
  • Автозамена битых ссылок из кэша живых URL.
  • Чёрные списки каналов и домен/IP.
  • Правила User-Agent по доменам.
  • EPG (XMLTV) с нечётким поиском.
  • Встроенный плеер mpv.
  • CLI/headless режим.

Установка и запуск

Требования

  • Python 3.10+
  • PyQt6
  • requests, urllib3
  • mpv (для встроенного плеера)

Установка зависимостей

Debian / Ubuntu / Mint

sudo apt update
sudo apt install -y python3 python3-pip python3-venv \
                    mpv libmpv-dev \
                    libxcb-cursor0 libxcb-xinerama0 \
                    adwaita-icon-theme

Fedora / RHEL

sudo dnf install -y python3 python3-pip \
                    mpv mpv-libs-devel \
                    xcb-util-cursor adwaita-icon-theme

Arch / Manjaro

sudo pacman -S --needed python python-pip \
                        mpv \
                        xcb-util-cursor adwaita-icon-theme

Python-пакеты

pip install PyQt6 requests urllib3

Запуск

python ksenia.py

Важно: встроенный плеер использует mpv --wid, который требует X11 (или XWayland). На «чистом» Wayland запускайте приложение так:

QT_QPA_PLATFORM=xcb python ksenia.py

Первый запуск: что делать

  1. Запустите приложение.
  2. Откройте Инструменты → Источники ссылок.
  3. Нажмите «🔍 Найти источники автоматически» — это live-поиск через GitHub API. Или добавьте свой источник вручную (локальный файл / URL).
  4. Нажмите «🔄 Обновить всё», чтобы загрузить каналы и наполнить кэш живых URL.
  5. Инструменты → Создать плейлист из источников или Файл → Открыть — начните работу.

EPG (программа передач) — опционально: Настройки → Общие → EPG по умолчанию — укажите свой URL (например, http://example.com/epg.xml).

Работа с плейлистами

Открытие

Файл → Открыть (Ctrl+O).

Поддержка кодировок: UTF-8, UTF-8-BOM, Windows-1251, CP1251.

Создание

Файл → Новый (Ctrl+N).

Сохранение

  • Ctrl+S — сохранить.
  • Ctrl+Shift+S — Сохранить как.
  • Файл → Сохранить всё — все вкладки.

Перед сохранением создаётся .bak (если включено).

Экспорт / импорт

  • Экспорт в CSV/JSON — все поля канала.
  • Импорт — добавить каналы из другого файла.
  • Stable-экспорт — с живой проверкой URL.

Экспорт/импорт настроек

Настройки → Экспорт настроек… — сохраняет все параметры в JSON (включая ширины столбцов таблицы).

Настройки → Импорт настроек… — загружает JSON и заменяет текущие настройки. После импорта требуется перезапуск приложения.

Редактирование каналов

Добавление

Каналы → Новый канал (Ctrl+Shift+A) или правый клик.

Удаление

  • Delete — текущий.
  • Ctrl+Shift+Delete — выбранные.
  • Каналы → Удалить каналы без ссылок.
  • Каналы → Удалить каналы без метаданных.

Перемещение

  • Ctrl+↑ / Ctrl+↓ — текущий.
  • Ctrl+Shift+↑ / Ctrl+Shift+↓ — группа.

Поиск

  • Обычный: по названию, группе, TVG-ID, URL.
  • Спец-префиксы:
    • is:orphan — без URL, но с метаданными.
    • is:broken — нерабочие.
    • is:working — рабочие.

Undo/Redo

Ctrl+Z / Ctrl+Y. История до 100 состояний.

Ссылки и проверка

Проверка

  • Ссылки → Проверить все ссылки.
  • Ссылки → Проверить выбранные ссылки.
  • Правый клик → Проверить ссылку.

Многопоточно (до 20 потоков), результаты кэшируются. Если в «Общих настройках» включён «Ограничивать число проверок», будет проверено не более max_channels_to_check каналов.

Замена

  • Ссылки → Заменить все ссылки (из кэша).
  • Ссылки → Заменить выбранные ссылки.

Внимание: работает только из кэша. Если кэш пуст — сначала «🔄 Обновить всё» в источниках.

Источники ссылок

Приложение не содержит встроенных источников. Пользователь добавляет их сам или находит через авто-поиск.

Менеджер

Инструменты → Источники ссылок.

Возможности:

  • Добавить / редактировать / удалить.
  • Включить / выключить.
  • Приоритет 1–10.
  • Автообновление.
  • 🔄 Обновить всё.
  • Импорт / экспорт JSON.

«🔍 Найти источники автоматически»

Выполняет live-поиск через GitHub API в момент запуска. Конкретные URL не зашиты в программу: они приходят в ответе API.

Что ищется:

  • GitHub Search API — по запросам «iptv m3u russia», «russian iptv playlist», «iptv ru m3u».
  • Репозиторий m3u.guide — через api.github.com/repos/m3uguide/playlists/contents/.

Никаких заранее прописанных ссылок на FAST-каналы или «известные репозитории» нет.

«🔄 Обновить всё»

Запускает SourcesRefreshWorker:

  1. Загрузка каналов.
  2. Проверка всех URL.
  3. Запись в кэш.
  4. Перестройка alive-индекса.

Обязательный шаг перед автозаменой.

Чёрные списки

ЧС каналов

Инструменты → Менеджер ЧС каналов.

Правило: имя и/или TVG-ID. Канал удаляется.

ЧС домен/IP

Инструменты → Менеджер ЧС домен/IP.

Правило: домен (с поддоменами) или IP. Ссылка очищается, канал остаётся, статус «🚫 Заблокирован ЧС домен/IP».

EPG

Встроенного EPG нет. Пользователь указывает свой URL в «Настройки → Общие → EPG по умолчанию» или в диалоге загрузки.

Загрузка

Инструменты → Загрузить EPG. Поддержка XMLTV и XMLTV.GZ.

Если в шапке плейлиста нет url-tvg, приложение предложит:

  1. использовать «EPG по умолчанию» из настроек (если он задан);
  2. или ввести URL вручную.

Применение

Инструменты → Применить метаданные из EPG.

Обновляет: tvg-id, tvg-name, tvg-logo, tvg-chno, epg_source.

Имя канала не перезаписывается.

Встроенный плеер (mpv)

Требования

  • Установленный mpv в PATH.
  • X11 или XWayland (на «чистом» Wayland используйте QT_QPA_PLATFORM=xcb).

Запуск

Двойной клик по каналу с URL, правый клик → Смотреть в плеере, или ▶ на панели.

Возможности

  • Воспроизведение с плейлистом текущего фильтра.
  • Переключение «Пред./След.».
  • Громкость, аспект (16:9, 4:3, 1:1).
  • Выбор аудио/видеодорожек, сохранение предпочтений.
  • Альтернативные ссылки из кэша источников.
  • Удаление ссылки, блокировка домена/IP.
  • Медиа-инфо, полноэкранный режим.

Кэш

SQLite

cache/editor_cache.db: url_status_cache, epg_entries, epg_channels, normalized_index.

Файловый кэш

cache/link_cache/*.json — по SHA-256 ключу URL.

Управление

Инструменты → Управление кэшем. Вкладки: Проверки, LinkCache, EPG.

При уменьшении TTL в настройках старые записи инвалидируются автоматически.

Настройки

Общие

Настройки → Общие настройки: шрифт, EXTVLCOPT, лимит проверок, дубликаты, ЧС при открытии, EPG-перезапись, порядок, отображение колонок, статус-бар, иконки, автообновление, автобэкап, EPG по умолчанию, авто-поиск источников.

В диалоге есть кнопка «Сбросить» — возвращает все параметры к значениям по умолчанию.

Замена ссылок

Настройки → Настройки замены ссылок:

  • Поиск — тип, порог, схожесть.
  • Нормализация — спецсимволы, скобки, эмодзи.
  • Автозамена — потоки, таймауты, кэш.
  • Сеть — таймауты, потоки, SSL.
  • Фильтрация — ЧС, домены.
  • EPG-метаданные — перезапись, нечёткий поиск.

При «Точном совпадении» пороги скрываются/дизейблятся. При включении «⚡ Быстрой замены» дизейблятся таймауты, повторы и проверка кандидатов. При выключении нечёткого поиска EPG дизейблятся его пороги.

В диалоге есть кнопка «Сбросить».

Экспорт / импорт

Настройки → Экспорт настроек… — сохраняет editor_config.json и ширины столбцов в один JSON.

Настройки → Импорт настроек… — загружает JSON и заменяет текущие настройки. После импорта требуется перезапуск приложения.

FAQ

Где настройки?
Linux — ~/.config/ksenia/, macOS — ~/Library/Application Support/Ksenia/, Windows — %APPDATA%\Ksenia\.

Почему приложение не содержит источников?
См. раздел «Важно: приложение не содержит встроенных источников». Юридически безопаснее предоставлять нейтральный инструмент, а не каталог.

Как добавить источник?
Инструменты → Источники ссылок → Добавить (вручную) или 🔍 Найти источники автоматически (live-поиск через GitHub API).

Как заменить все битые ссылки?

  1. Инструменты → Источники → 🔄 Обновить всё.
  2. Ссылки → Заменить все ссылки (из кэша).

Почему автозамена не находит ничего?
Работает только из кэша. Запустите «🔄 Обновить всё».

Как удалить ссылку, оставив канал?
Ссылки → Удалить выбранные ссылки.

Плеер не запускается на Wayland.
Запустите приложение с QT_QPA_PLATFORM=xcb.

Где взять EPG?
Приложение не содержит встроенного EPG. Укажите свой источник в Настройки → Общие → EPG по умолчанию.

Решение проблем

Не запускается

  1. Python 3.10+: python --version.
  2. pip install -r requirements.txt.
  3. Лог: ~/.config/ksenia/editor.log.

mpv не найден

# Linux
sudo apt install mpv

Ошибка SSL

Отключите проверку SSL в настройках сети.

Вопросы: Справка → Справка или GitHub.
