Ksenia M3U Editor — Руководство пользователя

Версия: 0.2  |  Платформа: Windows / Linux / macOS

Введение

Ksenia M3U Editor — десктопный редактор IPTV-плейлистов формата M3U/M3U8.

Возможности:

  • Открытие, редактирование, сохранение M3U/M3U8.
  • Несколько плейлистов в одном окне (вкладки).
  • Многопоточная проверка ссылок.
  • Автозамена битых ссылок из кэша живых URL.
  • Автоматический поиск источников в интернете (GitHub, m3u.guide, FAST).
  • Чёрные списки каналов и домен/IP.
  • Правила User-Agent по доменам.
  • EPG (XMLTV) с нечётким поиском.
  • Встроенный плеер VLC.
  • CLI/headless режим.

Установка и запуск

Требования

  • Python 3.10+
  • PyQt6
  • requests, urllib3
  • python-vlc (для плеера)

Установка зависимостей

Debian / Ubuntu / Mint

sudo apt update
sudo apt install -y python3 python3-pip python3-venv \
                    vlc libvlc-dev python3-vlc \
                    libxcb-cursor0 libxcb-xinerama0 \
                    adwaita-icon-theme

Fedora / RHEL

sudo dnf install -y python3 python3-pip \
                    vlc vlc-devel python3-vlc \
                    xcb-util-cursor adwaita-icon-theme

Arch / Manjaro

sudo pacman -S --needed python python-pip \
                        vlc python-vlc \
                        xcb-util-cursor adwaita-icon-theme

Python-пакеты

pip install PyQt6 requests urllib3 python-vlc

Запуск

python ksenia.py

  • ● работает
  • ● не работает

  • ● нет URL

Работа с плейлистами

Открытие

Файл → Открыть (Ctrl+O).

Поддержка кодировок: UTF-8, UTF-8-BOM, Windows-1251, CP1251.

Создание

Файл → Новый (Ctrl+N).

Сохранение

  • Ctrl+S — сохранить.
  • Ctrl+Shift+S — Сохранить как.
  • Файл → Сохранить всё — все вкладки.

Перед сохранением создаётся .bak (если включено).

Экспорт / импорт

  • Экспорт в CSV/JSON — все поля канала.
  • Импорт — добавить каналы из другого файла.
  • Stable-экспорт — с живой проверкой URL.

Stable-экспорт

Файл → Экспорт Stable-плейлиста — в результат попадают только живые URL с задержкой ≤ 1500 мс. Состояние пишется в stable_state.json.

Редактирование каналов

Добавление

Каналы → Новый канал (Ctrl+Shift+A) или правый клик.

Удаление

  • Delete — текущий.
  • Ctrl+Shift+Delete — выбранные.
  • Каналы → Удалить каналы без ссылок.
  • Каналы → Удалить каналы без метаданных.

Перемещение

  • Ctrl+↑ / Ctrl+↓ — текущий.
  • Ctrl+Shift+↑ / Ctrl+Shift+↓ — группа.
  • Перетаскивание строк мышью.

Поиск

  • Обычный: по названию, группе, TVG-ID, URL.
  • Спец-префиксы:
    • is:orphan — без URL, но с метаданными.
    • is:broken — нерабочие.
    • is:working — рабочие.

Undo/Redo

Ctrl+Z / Ctrl+Y. История до 100 состояний (на уровне диффов).

Ссылки и проверка

Проверка

  • Ссылки → Проверить все ссылки.
  • Ссылки → Проверить выбранные ссылки.
  • Правый клик → Проверить ссылку.

Многопоточно, результаты кэшируются в SQLite.

Замена

  • Ссылки → Заменить все ссылки (из кэша).
  • Ссылки → Заменить выбранные ссылки.

Внимание: работает только из кэша. Если кэш пуст — сначала «🔄 Обновить всё» в источниках.

Источники ссылок

Менеджер

Инструменты → Источники ссылок.

Возможности:

  • Добавить / редактировать / удалить.
  • Включить / выключить.
  • Приоритет 1–10.
  • Автообновление.
  • 🔄 Обновить всё.
  • 🔍 Найти источники автоматически — поиск публичных плейлистов в интернете.
  • 🧹 Удалить найденные — убрать всё, что добавлено авто-поиском.
  • Импорт / экспорт JSON.

Авто-поиск источников

Ищет публичные M3U/M3U8 в:

  • GitHub (известные репозитории + поиск).
  • m3u.guide.
  • FAST-плейлисты (Pluto, Samsung, Plex, ...).

Каждый найденный URL проверяется на доступность и свежесть (Last-Modified ≤ 30 дней). Источники «Забава» и Wink исключаются.

«🔄 Обновить всё»

Запускает SourcesRefreshWorker:

  1. Загрузка каналов.
  2. Проверка всех URL.
  3. Запись в кэш.
  4. Перестройка alive-индекса.

Обязательный шаг перед автозаменой.

Чёрные списки

ЧС каналов

Инструменты → Менеджер ЧС каналов.

Правило: имя и/или TVG-ID. Канал удаляется.

ЧС домен/IP

Инструменты → Менеджер ЧС домен/IP.

Правило: домен (с поддоменами) или IP. Ссылка очищается, канал остаётся, статус «🚫 Заблокирован ЧС домен/IP».

Инструменты → User-Agent по доменам.

EPG

Загрузка

Инструменты → Загрузить EPG. Поддержка XMLTV и XMLTV.GZ.

Применение

Инструменты → Применить метаданные из EPG.

Обновляет: tvg-id, tvg-name, tvg-logo, tvg-chno, epg_source.

Имя канала не перезаписывается.

Встроенный плеер

Запуск

Двойной клик по каналу с URL, правый клик → Смотреть в плеере, или ▶ на панели.

Возможности

  • Воспроизведение с плейлистом текущего фильтра.
  • Переключение «Пред./След.».
  • Громкость, аспект (16:9, 4:3, 1:1).
  • Снимок кадра.
  • Медиа-инфо (I).
  • Полноэкранный режим.

Кэш

SQLite

cache/editor_cache.db: url_status_cache, epg_entries, epg_channels.

Файловый кэш

cache/link_cache/*.json — по SHA-256 ключу URL.

Управление

Инструменты → Управление кэшем. Вкладки: Проверки, LinkCache, EPG.

Настройки

Общие

Настройки → Общие настройки: шрифт, EXTVLCOPT, лимит проверок, дубликаты, ЧС при открытии, EPG-перезапись, порядок, отображение колонок, статус-бар, иконки, автообновление, автобэкап, параметры авто-поиска источников.

Замена ссылок

Настройки → Настройки замены ссылок:

  • Поиск — тип, порог, схожесть.
  • Нормализация — спецсимволы, скобки, эмодзи.
  • Автозамена — потоки, таймауты, кэш.
  • Сеть — таймауты, потоки, SSL.
  • Фильтрация — ЧС, домены.
  • EPG-метаданные — перезапись, нечёткий поиск.

FAQ

Где настройки?
Linux — $XDG_CONFIG_HOME/ksenia/ (по умолчанию ~/.config/ksenia/), macOS — ~/Library/Application Support/Ksenia/, Windows — %APPDATA%\Ksenia\.

Как заменить все битые ссылки?

  1. Инструменты → Источники → 🔄 Обновить всё.
  2. Ссылки → Заменить все ссылки (из кэша).

Почему автозамена не находит ничего?
Работает только из кэша. Запустите «🔄 Обновить всё».

Как удалить ссылку, оставив канал?
Ссылки → Удалить выбранные ссылки.

Как открыть справку?
Нажмите F1 или Справка → Руководство пользователя. Откроется встроенный браузер.

Решение проблем

Не запускается

  1. Python 3.10+: python --version.
  2. pip install PyQt6 requests urllib3 python-vlc.
  3. Лог: $XDG_CONFIG_HOME/ksenia/editor.log.

VLC не найден

# Linux
sudo apt install vlc libvlc-dev
pip install python-vlc

Файл справки не найден

Убедитесь, что папка help с index.html находится рядом с ksenia.py.

Ошибка SSL

Отключите проверку SSL в настройках сети.
