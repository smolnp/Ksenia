# Ksenia M3U Editor

Редактор M3U-плейлистов для управления IPTV-каналами:
проверка ссылок, автопочинка, чёрные списки, EPG, шаблоны
категорий, встроенный проигрыватель **mpv**, определение
фактического разрешения через **ffprobe**.

Версия: **0.2.3** · Лицензия: **GPL-3.0-or-later**

---

## ⚠️ Важно

**Приложение не содержит встроенных источников.** Ни IPTV-плейлистов,
ни EPG, ни FAST-каналов, ни «известных» репозиториев. Автоматического
поиска источников нет.

Источники добавляет **только пользователь** — вручную (локальный
файл или URL) через «Инструменты → Управление источниками».
EPG — свой URL в «Настройки → Общие → Программа передач по умолчанию».

Ответственность за использование конкретных источников лежит на
пользователе и определяется законодательством его страны.

## Установка

**Требования:** Python 3.10+, PyQt6, requests, urllib3, defusedxml,
`mpv` (для проигрывателя), `ffprobe` (для разрешения, входит в FFmpeg).

**Linux (Debian/Ubuntu/Mint):**
```bash
sudo apt install -y python3 python3-pip python3-venv \
                    mpv libmpv-dev ffmpeg \
                    libxcb-cursor0 libxcb-xinerama0 \
                    adwaita-icon-theme
pip install PyQt6 requests urllib3 defusedxml
