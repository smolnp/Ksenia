# Ksenia M3U Editor

Редактор M3U-плейлистов для управления IPTV-каналами с проверкой
ссылок, управлением источниками, чёрными списками, поддержкой EPG
и встроенным плеером VLC.

Версия: **0.1**

---

## Возможности

### Управление плейлистами

- Открытие и сохранение M3U/M3U8.
- Работа с несколькими плейлистами в одном окне (вкладки).
- Импорт/экспорт: M3U/M3U8, CSV, JSON.
- Автоопределение кодировки: UTF-8, UTF-8-BOM, Windows-1251, CP1251.
- Отслеживание несохранённых изменений.
- Автобэкап файла перед сохранением (`.bak`).
- Список недавних файлов.
- Редактор заголовка плейлиста: `#EXTM3U`, `url-tvg`, `#PLAYLIST`,
  пользовательские атрибуты.

### Редактирование каналов

- Встроенный редактор таблицы с прямым редактированием ячеек.
- Добавление, удаление, копирование, вырезание и вставка каналов.
- Перемещение каналов вверх/вниз — одиночное и групповое.
- Пакетное переименование групп каналов.
- Массовая правка: имя, группа, TVG-ID, TVG-Logo, User-Agent.
- Поиск по названию, группе, TVG-ID и URL.
- Спец-префиксы поиска: `is:orphan`, `is:broken`, `is:working`.
- Фильтрация по группам через выпадающий список.
- Сортировка по любому столбцу.
- Undo/Redo на уровне диффов (added/removed/changed), а не полных
  снимков плейлиста.
- Подсветка «осиротевших» каналов (без URL, но с метаданными).

### Метаданные каналов

- Редактирование названий, групп, TVG-ID, логотипов, TVG-Name.
- Управление `User-Agent`, `Referer` и произвольными HTTP-заголовками.
- Пакетное удаление метаданных: `tvg-id`, `tvg-name`, `tvg-logo`,
  `group-title`, User-Agent.
- Автоматическое обновление `#EXTINF` при изменении.
- Поддержка `catchup`, `catchup-source`, `catchup-days`, `timeshift`,
  `tvg-shift`, `tvg-chno`, `tvg-rec`, `audio-track`.
- `EXTVLCOPT` сохраняется и восстанавливается.

### Ссылки и сеть

- Многопоточная проверка URL (`ThreadPoolExecutor`).
- HEAD-запрос перед GET для не-стримовых URL, GET сразу для
  `.m3u8` / `.mpd`.
- Автоматическая замена битых ссылок из кэша живых URL.
- Умный поиск альтернативных ссылок с оценкой качества.
- Удаление всех ссылок или только битых.
- Классификация ответов: работает, 404, 403 (геоблок), таймаут,
  DNS-ошибка, ошибка соединения, неподдерживаемый протокол.
- Протоколы: HTTP, HTTPS, RTMP, RTSP, UDP, TCP, RTP, SRT, RIST, HLS.
- Настраиваемые таймауты, повторы и задержки.
- Игнорирование SSL-ошибок по умолчанию.
- Пул HTTP-сессий на поток с автоматической пересборкой при росте
  `pool_size`.
- `Icy-MetaData`, `VLC/3.0.20` User-Agent, `keep-alive`.
- Батчинг записи результатов в SQLite (`executemany`).

### Источники ссылок

- Управление несколькими источниками: локальные файлы и онлайн.
- Приоритезация источников (1–10).
- Автообновление по расписанию с экспоненциальным backoff при ошибках.
- Кэширование загруженных плейлистов для быстрого доступа.
- Кэш живых URL (`url_status_cache`, SQLite, WAL).
- «🔄 Обновить всё» — загрузка, проверка URL и перестройка индекса
  живых URL в одном действии.
- Применение чёрных списков и правил User-Agent при загрузке источника.
- Поддержка кодировок: UTF-8, Windows-1251, CP1251, KOI8-R, CP866.
- Индексы `_name_index` (по имени) и `_alive_index` (живые URL) в памяти
  с LRU-эвикцией.
- Экспорт/импорт источников в JSON.

### Чёрные списки и фильтрация

- Чёрный список каналов: по названию и/или TVG-ID — канал удаляется.
- Чёрный список домен/IP: с поддоменами, заметкой и датой —
  ссылка очищается, канал сохраняется с метаданными.
- Кэш «host → blocked» через `OrderedDict` (LRU, 8192 записей).
- Импорт/экспорт чёрных списков в JSON.
- Временные и небезопасные домены (списком в настройках).
- Единая точка применения фильтров при открытии файла
  (`apply_filters_on_file_open`).

### Правила User-Agent по доменам

- Автоматическая установка User-Agent для каналов по домену.
- Пустое значение UA = удаление User-Agent у каналов с этим доменом.
- Кэш «host → (matched, ua)» с корректной обработкой пустого правила.
- Пакетное применение ко всем каналам текущего плейлиста.

### EPG

- Загрузка XMLTV и XMLTV.GZ по URL.
- Разбор `<channel>` и `<programme>`, приоритеты источников.
- Применение метаданных: `tvg-id`, `tvg-name`, `tvg-logo`, `tvg-chno`.
- Нечёткий поиск по имени канала (`SequenceMatcher` + токены + Jaccard).
- Порог нечёткого поиска, мин. длина имени, мин. отрыв от 2-го места.
- Кэш EPG-записей и EPG-каналов в SQLite с TTL.
- Просмотр текущей программы через контекстное меню.
- Поле `meta.epg_source` фиксирует источник EPG для канала.

### Поиск и нормализация

- Умная нормализация названий (исправление cp1251/latin1 → UTF-8).
- Игнорирование информации о качестве: 720p, 1080p, 4K, UHD, HD, SD.
- Игнорирование эмодзи и специальных символов.
- Игнорирование технических тегов: `[Geo-blocked]`, `[Not 24/7]` и др.
- Нечёткий поиск (`SequenceMatcher`) и Jaccard по токенам.
- Настраиваемые пороги совпадения.

### Поиск дубликатов и сравнение

- Дубликаты по URL, по нормализованному имени или по комбинации с TVG-ID.
- Удаление или показ без удаления.
- Предпросмотр результатов с ограничением по количеству строк.
- Сравнение двух плейлистов: только в текущем, только во втором,
  в обоих, разные URL.
- Экспорт сравнения в CSV и JSON.

### Кэш и производительность

- Единый SQLite-кэш: проверки ссылок, EPG-записи, EPG-каналы.
- Отдельный файловый кэш плейлистов (`link_cache`, SHA-256 ключи).
- LRU-эвикция кэша плейлистов по возрасту и размеру.
- Индексы SQLite для частых запросов.
- Батчевая запись результатов проверок.
- Кэш результатов проверок с TTL.
- Управление кэшем из GUI: очистка по разделам, VACUUM, лимиты.

### Плеер (VLC)

- Встроенный плеер на `python-vlc`.
- Список воспроизведения, переключение каналов в плеере.
- Громкость, аспект, снимок кадра.
- Медиа-инфо: метаданные VLC, статистика, треки (аудио/видео/субтитры).
- Неблокирующее переключение каналов, `network-caching`, авто-reconnect.
- Настраиваемая полноэкранность, сохранение громкости.

### Интерфейс и настройки

- Подсветка синтаксиса M3U с цветовой кодировкой.
- Контекстное меню с быстрыми действиями.
- Настраиваемая панель инструментов и статус-бар.
- Горячие клавиши.
- Система Undo/Redo с историей.
- Настройки: общие, замена ссылок, фильтрация, EPG, кэш.
- Управление размером шрифта таблицы.
- Иконки из системной темы (или стандартные из Qt).
- Сохранение всех настроек в `editor_config.json`.

### CLI/headless

- Полностью безголовый режим без запуска GUI (`--headless`).
- Загрузка списка источников из JSON (`--sources-file`).
- Экспорт обычный или `Stable` с живой перепроверкой (`--export-stable`).
- Настройка таймаута и воркеров.
- Применение ЧС каналов и ЧС домен/IP.
- Применение правил User-Agent.
- Информативный вывод в stdout/stderr.

## Установка

### Требования

- Python 3.10+
- PyQt6
- requests
- urllib3
- `python-vlc` (для встроенного плеера)

### Linux

```bash
# Debian / Ubuntu / Mint / Pop!_OS
sudo apt update
sudo apt install -y python3 python3-pip python3-venv \
                    vlc libvlc-dev python3-vlc \
                    libxcb-cursor0 libxcb-xinerama0 \
                    adwaita-icon-theme

# Fedora / RHEL / CentOS Stream
sudo dnf install -y python3 python3-pip \
                    vlc vlc-devel python3-vlc \
                    xcb-util-cursor adwaita-icon-theme

# Arch / Manjaro / EndeavourOS
sudo pacman -S --needed python python-pip \
                        vlc python-vlc \
                        xcb-util-cursor adwaita-icon-theme
