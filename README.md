# Ksenia M3U Editor


Редактор M3U-плейлистов для управления IPTV-каналами с проверкой
ссылок, управлением источниками, чёрными списками, поддержкой EPG,
встроенным плеером **mpv** и **встроенной справкой (F1)**.

Версия: **0.2.2**

---

## ⚠️ Важно: приложение не содержит встроенных источников

**Ksenia M3U Editor — это инструмент, а не каталог.**

Приложение **не содержит** заранее прописанных ссылок на:

- IPTV-плейлисты (`.m3u`, `.m3u8`);
- EPG (`.xml`, `.xml.gz`);
- FAST-каналы (Pluto, Samsung, Plex, Tubi, Roku, Xumo и т.п.);
- «известные» репозитории с плейлистами.

**Что это значит на практике:**

1. **Источники добавляет пользователь** — вручную (локальный файл
   или URL) или через «🔍 Найти источники автоматически».
2. **Авто-поиск — это live-запрос к GitHub API** в момент
   выполнения. Конкретные URL не зашиты в программу: они приходят
   в ответе API.
3. **EPG не встроен.** Пользователь указывает свой источник EPG в
   «Настройки → Общие → EPG по умолчанию» или в диалоге загрузки
   при первом запуске.

**Юридическая позиция:** ответственность за использование
конкретных источников лежит на пользователе и определяется
законодательством его страны. Разработчик предоставляет
нейтральный инструмент для редактирования плейлистов, которые
пользователь получил самостоятельно.

## Что нового в 0.2.2

Исправлены ошибки, найденные при аудите кода:

- **Утечка `#EXTVLCOPT` между каналами** в `M3UParser` —
  `pending_vlcopts` очищаются после `_flush_pending`.
- **Потеря канала при undo с коллизией uid** в
  `PlaylistTab._apply_diff` — канал больше не пересоздаётся с новым
  uid, запись с конфликтом пропускается с логом.
- **Откат undo при исключении в `_edit_channels`** — блок
  корректно откатывает стек undo и перестраивает модель.
- **Undo для диалога поиска дубликатов** —
  `DuplicateFinderDialog` работает с копией списка, а
  `PlaylistTab` применяет изменения только после
  подтверждения.
- **TTL `normalized_index` в статистике** —
  `CacheManager.get_stats` использует собственный TTL (24 ч), а не
  TTL EPG.
- **Порядок кодировок в `decode_m3u_bytes`** —
  `utf-8-sig` перед `utf-8`, чтобы BOM не попадал в `#EXTM3U`.
- **Громкость плеера** — применяется сразу после подключения IPC,
  а не только при смене громкости.
- **Алиасы синонимов** — `_apply_synonyms` корректно обрабатывает
  имена с тегом качества в скобках («Первый канал (HD)»).
- **`generator.py`** — один `requests.Session` на воркер, а не
  новый на каждый URL.
- **`_PlaylistCreateTask`** — регистрируется в реестре воркеров
  (`ApplicationCore._workers`), корректно останавливается при
  выходе.
- **Round-trip имён с `"` и `\\`** — `M3UParser.extract_name`
  снимает экранирование, наложенное `update_extinf`.
- **`update_source`** — проверяет коллизию имён с другим
  источником.
- **`canonical_key` (stable_key)** — теперь применяет `_SYNONYMS`
  (Perviy Kanal == Первый канал).
- **`BaseJsonStore`** — deepcopy дефолта и предупреждение при
  несовпадении типа в файле.
- **`x-tvg-url`** — поддерживается как синоним `url-tvg` в шапке
  плейлиста.
- **`ChannelData.restore_from_dict`** — валидация `status_text`
  по известным значениям `StatusText`.
- **`ChannelData.get_url_foreground`** — учитывает `url_status`,
  если `link_quality` не установлен.
- **`DomainBlacklistRule._ip_eq`** — корректно сравнивает IPv4 с
  IPv4-mapped IPv6.
- **`_is_valid_url_candidate`** — ужесточён (требует `/` или `.`).

## Возможности

### Управление плейлистами

- Открытие и сохранение M3U/M3U8.
- Работа с несколькими плейлистами в одном окне (вкладки).
- Импорт/экспорт: M3U/M3U8, CSV, JSON.
- Автоопределение кодировки: UTF-8 (с BOM и без), Windows-1251,
  CP1251.
- Отслеживание несохранённых изменений.
- Автобэкап файла перед сохранением (`.bak`).
- Список недавних файлов.
- Редактор заголовка плейлиста: `#EXTM3U`, `url-tvg`/`x-tvg-url`,
  `#PLAYLIST`, пользовательские атрибуты.

### Редактирование каналов

- Встроенный редактор таблицы с прямым редактированием ячеек.
- Добавление, удаление, копирование, вырезание и вставка.
- Перемещение каналов вверх/вниз — одиночное и групповое.
- Drag & drop.
- Пакетное переименование групп.
- Массовая правка: имя, группа, TVG-ID, TVG-Logo, User-Agent.
- Поиск по названию, группе, TVG-ID и URL.
- Спец-префиксы поиска: `is:orphan`, `is:broken`, `is:working`.
- Фильтрация по группам и по статусу URL.
- Кнопка «🔁 Дубликаты» с цветовой подсветкой.
- Сортировка по любому столбцу.
- Undo/Redo (диффы, до 100 состояний).
- Подсветка «осиротевших» каналов.

### Метаданные каналов

- Редактирование названий, групп, TVG-ID, логотипов, TVG-Name.
- Управление `User-Agent`, `Referer` и произвольными HTTP-заголовками.
- Пакетное удаление метаданных.
- Автоматическое обновление `#EXTINF` при изменении.
- Поддержка `catchup`, `catchup-source`, `catchup-days`,
  `timeshift`, `tvg-shift`, `tvg-chno`, `tvg-rec`, `audio-track`.
- `EXTVLCOPT` сохраняется и восстанавливается.

### Ссылки и сеть

- Многопоточная проверка URL (`ThreadPoolExecutor`).
- HEAD-запрос перед GET (кроме стримов).
- Автоматическая замена битых ссылок из кэша живых URL.
- Умный поиск альтернативных ссылок с оценкой качества.
- Удаление всех ссылок или только битых.
- Классификация ответов: работает, 404, 403 (геоблок), таймаут,
  DNS-ошибка, ошибка соединения, неподдерживаемый протокол.
- Настраиваемые таймауты, повторы, SSL-проверка.
- Пул HTTP-сессий на поток.
- Батчинг записи результатов в SQLite.

### Источники ссылок

> **Приложение не содержит встроенных источников.** Пользователь
> добавляет их сам или находит через авто-поиск.

- Управление источниками: локальные файлы и онлайн-URL.
- Приоритезация (1–10).
- Автообновление с экспоненциальным backoff.
- Кэш загруженных плейлистов.
- Кэш живых URL (`url_status_cache`, SQLite, WAL).
- «🔄 Обновить всё» — загрузка, проверка URL, rebuild alive-индекса.
- **«🔍 Найти источники автоматически»** — live-поиск через
  GitHub API. Никаких заранее прописанных URL.
- «🧹 Удалить найденные» — очистка авто-найденных.
- Применение ЧС и правил UA при загрузке источника.
- Поддержка кодировок: UTF-8, Windows-1251, CP1251, KOI8-R, CP866.
- Индексы `_name_index` и `_alive_index` с LRU-эвикцией.
- Экспорт/импорт источников в JSON.

### Чёрные списки и фильтрация

- ЧС каналов: по имени и/или TVG-ID (удаление).
- ЧС домен/IP: с поддоменами, заметкой и датой (очистка ссылки).
- LRU-кэш «host → blocked» (8192).
- Импорт/экспорт в JSON.
- Временные и небезопасные домены.

### Правила User-Agent по доменам

- Автоматическая установка User-Agent по домену.
- Пустое значение UA — удаление User-Agent.
- Кэш «host → (matched, ua)».
- Пакетное применение к текущему плейлисту.

### EPG

> **Встроенного EPG нет.** Пользователь указывает свой URL.

- Загрузка XMLTV и XMLTV.GZ по URL.
- Разбор `<channel>` и `<programme>` с приоритетами источников.
- Применение метаданных: `tvg-id`, `tvg-name`, `tvg-logo`,
  `tvg-chno`.
- Нечёткий поиск (`SequenceMatcher` + токены + Jaccard).
- Настройка порога, мин. длины, мин. отрыва.
- Кэш EPG в SQLite с TTL.
- Поле `meta.epg_source`.

### Сравнение плейлистов

- Построчный diff (как git diff).
- Режим «только каналы» (с сохранением `#EXTVLCOPT`).
- Экспорт diff в `.diff` / `.patch`.
- Unified diff.

### Кэш и производительность

- SQLite-кэш: проверки, EPG-записи, EPG-каналы,
  `normalized_index`.
- Файловый кэш плейлистов (`link_cache`, SHA-256 ключи).
- LRU-эвикция по возрасту и размеру.
- Батчевая запись.
- Управление кэшем из GUI.

### Встроенная справка

- **F1** — встроенный браузер справки (`HelpBrowser`).
- Оглавление из `<h2 id>`.
- Навигация: назад / вперёд / домой / обновить.
- Горячие клавиши: `Alt+←`, `Alt+→`, `Home`, `F5`.

### Плеер (mpv)

- Встроенный плеер на `mpv` через `--wid` + JSON IPC.
- Требует X11 или XWayland. На «чистом» Wayland запускайте с
  `QT_QPA_PLATFORM=xcb`.
- Список воспроизведения, переключение каналов.
- Громкость, аспект, снимок кадра.
- Выбор аудио/видеодорожек, сохранение предпочтений.
- Альтернативные ссылки из кэша источников.
- Удаление ссылки, блокировка домена/IP.
- Медиа-инфо, полноэкранный режим.

### CLI/headless

- Полностью безголовый режим (`--headless`).
- Загрузка источников из JSON.
- Экспорт обычный или `Stable` с живой перепроверкой.
- Настройка таймаута и воркеров.
- Применение ЧС каналов и ЧС домен/IP.
- Применение правил User-Agent.

## Установка

### Требования

- Python 3.10+
- PyQt6
- requests
- urllib3
- `mpv` (для встроенного плеера)

### Linux (Debian / Ubuntu / Mint)

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv \
                    mpv libmpv-dev \
                    libxcb-cursor0 libxcb-xinerama0 \
                    adwaita-icon-theme
pip install PyQt6 requests urllib3
