# Ksenia M3U Editor

Редактор M3U-плейлистов для управления IPTV-каналами с проверкой
ссылок, управлением источниками, чёрными списками, поддержкой EPG,
встроенным плеером VLC и **встроенной справкой (F1)**.

Версия: **0.2**

---

  `help/index.html` с навигацией, оглавлением и обновлением.

## Возможности

### Управление плейлистами

- Открытие и сохранение M3U/M3U8.
- Работа с несколькими плейлистами в одном окне (вкладки).
- Импорт/экспорт: M3U/M3U8, CSV, JSON.
- Автоопределение кодировки: UTF-8, UTF-8-BOM, Windows-1251, CP1251.
- Отслеживание несохранённых изменений.
- Автобэкап файла перед сохранением (`.bak`).
- Список недавних файлов.
- Редактор заголовка плейлиста: `#EXTM3U`, `url-tvg`, `#PLAYLIST`,
  пользовательские атрибуты.

### Редактирование каналов

- Встроенный редактор таблицы с прямым редактированием ячеек.
- Добавление, удаление, копирование, вырезание и вставка каналов.
- Перемещение каналов вверх/вниз — одиночное и групповое.
- Drag & drop.
- Пакетное переименование групп каналов.
- Массовая правка: имя, группа, TVG-ID, TVG-Logo, User-Agent.
- Поиск по названию, группе, TVG-ID и URL.
- Спец-префиксы поиска: `is:orphan`, `is:broken`, `is:working`.
- Фильтрация по группам через выпадающий список.
- Кнопка «🔁 Дубликаты» — показать только дубликаты
  с групповой цветовой подсветкой.
- Сортировка по любому столбцу.
- Undo/Redo (диффы, до 100 состояний).
- Подсветка «осиротевших» каналов.

### Метаданные каналов

- Редактирование названий, групп, TVG-ID, логотипов, TVG-Name.
- Управление `User-Agent`, `Referer` и произвольными HTTP-заголовками.
- Пакетное удаление метаданных.
- Автоматическое обновление `#EXTINF` при изменении.
- Поддержка `catchup`, `catchup-source`, `catchup-days`, `timeshift`,
  `tvg-shift`, `tvg-chno`, `tvg-rec`, `audio-track`.
- `EXTVLCOPT` сохраняется и восстанавливается.

### Ссылки и сеть

- Многопоточная проверка URL (`ThreadPoolExecutor`).
- HEAD-запрос перед GET (кроме стримов).
- Автоматическая замена битых ссылок из кэша живых URL.
- Умный поиск альтернативных ссылок с оценкой качества.
- Удаление всех ссылок или только битых.
- Классификация ответов: работает, 404, 403 (геоблок), таймаут,
  DNS-ошибка, ошибка соединения, неподдерживаемый протокол.
- Настраиваемые таймауты, повторы, SSL-проверка.
- Пул HTTP-сессий на поток.
- Батчинг записи результатов в SQLite.

### Источники ссылок

- Управление источниками: локальные файлы и онлайн.
- Приоритезация (1–10).
- Автообновление с экспоненциальным backoff.
- Кэш загруженных плейлистов.
- Кэш живых URL (`url_status_cache`, SQLite, WAL).
- «🔄 Обновить всё» — загрузка, проверка URL, rebuild alive-индекса.
- **«🔍 Найти источники автоматически»** — поиск публичных плейлистов
  (GitHub, m3u.guide, FAST).
- «🧹 Удалить найденные» — очистка авто-найденных.
- Применение ЧС и правил UA при загрузке источника.
- Поддержка кодировок: UTF-8, Windows-1251, CP1251, KOI8-R, CP866.
- Индексы `_name_index` и `_alive_index` с LRU-эвикцией.
- Экспорт/импорт источников в JSON.

### Чёрные списки и фильтрация

- ЧС каналов: по имени и/или TVG-ID (удаление).
- ЧС домен/IP: с поддоменами, заметкой и датой (очистка ссылки).
- LRU-кэш «host → blocked» (8192).
- Импорт/экспорт в JSON.
- Временные и небезопасные домены.

### Правила User-Agent по доменам

- Автоматическая установка User-Agent по домену.
- Пустое значение UA — удаление User-Agent.
- Кэш «host → (matched, ua)».
- Пакетное применение к текущему плейлисту.

### EPG

- Загрузка XMLTV и XMLTV.GZ по URL.
- Разбор `<channel>` и `<programme>` с приоритетами источников.
- Применение метаданных: `tvg-id`, `tvg-name`, `tvg-logo`, `tvg-chno`.
- Нечёткий поиск (`SequenceMatcher` + токены + Jaccard).
- Настройка порога, мин. длины, мин. отрыва.
- Кэш EPG в SQLite с TTL.
- Поле `meta.epg_source`.

### Сравнение плейлистов

- Построчный diff (как git diff).
- Режим «только каналы» (с сохранением `#EXTVLCOPT`).
- Экспорт diff в `.diff` / `.patch`.
- Unified diff.

### Кэш и производительность

- SQLite-кэш: проверки, EPG-записи, EPG-каналы.
- Файловый кэш плейлистов (`link_cache`, SHA-256 ключи).
- LRU-эвикция по возрасту и размеру.
- Батчевая запись.
- Управление кэшем из GUI.

### Встроенная справка

- **F1** — встроенный браузер справки (`HelpBrowser`).
- Оглавление из `<h2 id>`.
- Навигация: назад / вперёд / домой / обновить.
- Горячие клавиши: `Alt+←`, `Alt+→`, `Home`, `F5`.

### Плеер (VLC)

- Встроенный плеер на `python-vlc`.
- Список воспроизведения, переключение каналов.
- Громкость, аспект, снимок кадра.
- Медиа-инфо (метаданные, статистика, треки).
- Неблокирующее переключение, `network-caching`, авто-reconnect.
- Сохранение громкости, полноэкранность.

### CLI/headless

- Полностью безголовый режим (`--headless`).
- Загрузка источников из JSON.
- Экспорт обычный или `Stable` с живой перепроверкой.
- Настройка таймаута и воркеров.
- Применение ЧС каналов и ЧС домен/IP.
- Применение правил User-Agent.

## Установка

### Требования

- Python 3.10+
- PyQt6
- requests
- urllib3
- `python-vlc` (для встроенного плеера)

### Linux (Debian / Ubuntu / Mint)

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv \
                    vlc libvlc-dev python3-vlc \
                    libxcb-cursor0 libxcb-xinerama0 \
                    adwaita-icon-theme
pip install PyQt6 requests urllib3 python-vlc
